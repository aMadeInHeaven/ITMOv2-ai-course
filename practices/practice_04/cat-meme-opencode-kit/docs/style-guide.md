# Style guide проекта «Котомемы»

1. Компонент должен быть понятен по HTML: список — это список, карточка — самостоятельная статья, форма имеет явные `label`.
2. CSS строится от мобильного экрана. Используй дизайн-токены в `:root`, сетку без жёстких высот и заметный `:focus-visible`.
3. Пользовательские данные вставляй только безопасными DOM API (`textContent`, `setAttribute` после проверки URL). Не используй `innerHTML` для данных формы или `localStorage`.
4. Состояние хранится в одном месте. Чтение `localStorage` должно переживать повреждённый JSON и возвращать пустой список, не падение всего приложения.
5. Проверяй поведение через публичный интерфейс страницы. Не привязывай тесты к внутренним именам функций и не ослабляй runner ради зелёного результата.

## Визуальное направление

- Настроение: весёлое, лёгкое, «интернет-журнал о котах», но не детское.
- Палитра: тёплый молочный фон, графитовый текст, коралловый акцент и один холодный дополнительный цвет.
- Типографика: крупный короткий заголовок, комфортный основной текст, не более двух гарнитур.
- Карточки: одинаковый радиус, мягкая тень, изображение с фиксированным соотношением сторон через `aspect-ratio` и `object-fit: cover`.
- Анимация: только короткая обратная связь; учитывай `prefers-reduced-motion`.

## Хороший пример

```js
function renderCard(card) {
  const article = document.createElement("article");
  const title = document.createElement("h2");
  const image = document.createElement("img");

  title.textContent = card.title;
  image.src = card.imageUrl;
  image.alt = card.altText;
  article.append(image, title);
  return article;
}
```

Здесь семантика остаётся видимой, а пользовательский текст не интерпретируется как HTML.
