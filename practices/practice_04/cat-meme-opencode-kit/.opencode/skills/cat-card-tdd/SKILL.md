# Skill: Cat Card TDD

## Назначение
Процедура разработки компонентов карточек и форм через TDD.

## Процедура:
1. Прочитай контракт в `docs/requirements.md` и сценарии в `references/acceptance-scenarios.md`.
2. Напиши падающий тест (Red).
3. Напиши минимальную реализацию без `innerHTML` (Green).
4. Проверь код через `node scripts/check.mjs`.
