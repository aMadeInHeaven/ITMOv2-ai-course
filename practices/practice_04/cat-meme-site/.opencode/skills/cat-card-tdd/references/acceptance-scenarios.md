# Сценарии приёмки

## Фича A: Каталог

- A1: На главной отображается минимум 6 стартовых карточек.
- A2: Каждая карточка содержит заголовок, картинку с непустым alt.
- A3: Ошибка загрузки картинки показывает доступный плейсхолдер.

## Фича B: Добавление карточки

- B1: Валидная отправка добавляет карточку первой в список без перезагрузки.
- B2: Карточки сохраняются и читаются из localStorage (cat-meme-cards:v1).
- B3: Ошибочные URL (javascript:, data:) и пустые поля отклоняются с показом ошибки.

## Фича C: Интеграция

- C1: MCP публикует инструмент `prepare_cat_card` через `tools/list`.
- C2: Инструмент нормализует валидную карточку и возвращает структурированный результат.
- C3: Опасный URL возвращает контролируемую ошибку, а неизвестный инструмент — JSON-RPC ошибку `-32601`.
- C4: `npm run check` последовательно запускает тесты, сборку и интеграционный MCP-тест.
