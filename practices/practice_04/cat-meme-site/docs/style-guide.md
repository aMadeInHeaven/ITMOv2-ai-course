# Визуальный гайд

## Направление

«Лабораторный журнал ночной команды»: глубокий графитовый фон, холодный бирюзовый акцент для технических состояний и тёплый жёлтый для котомемов. Интерфейс должен выглядеть как законченный учебный артефакт, а не как шаблонный лендинг.

## Правила

- Основной текст — не меньше 16 px, подписи — не меньше 14 px.
- Карточки используют плотную сетку с заметной типографикой и радиусом 20–28 px.
- Цвет статуса всегда дублируется текстом или символом.
- Фокус клавиатуры заметен на всех интерактивных элементах.
- На ширине до 760 px форма, карточки и отчёт переходят в одну колонку без горизонтального скролла.
- Анимации короткие и отключаются через `prefers-reduced-motion`.
