# Требования к практике 04

README в переданной рабочей копии отсутствовал, поэтому эта спецификация фиксирует критерии, которые уже были заложены в скилл, MCP и проверочный runner проекта.

## Функциональность

1. На странице есть минимум шесть стартовых карточек с заголовком, изображением и непустым `alt`.
2. Пользователь может добавить карточку без перезагрузки страницы.
3. Карточки сохраняются в `localStorage` под ключом `cat-meme-cards:v1` и безопасно восстанавливаются.
4. Пустые поля, невалидные адреса и протоколы кроме `http:`/`https:` отклоняются с понятным сообщением.
5. Ошибка изображения показывает доступный плейсхолдер.
6. Пользовательский текст не вставляется через `innerHTML`.

## Интеграция OpenCode

1. Проектный скилл лежит в `.opencode/skills/cat-card-tdd/SKILL.md`, имеет валидное имя и узкое описание области применения.
2. Локальный MCP объявлен непосредственно в объекте `mcp` файла `opencode.json`.
3. MCP поддерживает `initialize`, `ping`, `tools/list` и `tools/call` для `prepare_cat_card`.
4. Единая команда `npm run check` проверяет unit-тесты, production-сборку и реальный обмен с MCP-процессом.

## Отчёт

Страница одновременно демонстрирует продукт и содержит проверяемую матрицу критериев: каталог, форма, безопасность, skill, MCP и автоматические проверки.
