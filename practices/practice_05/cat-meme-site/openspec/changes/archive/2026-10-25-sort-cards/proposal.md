# Proposal

## Why

Каталог котомемов сейчас всегда отображается в исходном порядке: сначала добавленные пользователем карточки (новые — сверху), затем фиксированный набор стартовых. Пользователю не хватает возможности быстро найти карточку по подписи — нужна сортировка по названию (А–Я) и понятный сброс к исходному порядку.

## What Changes

- Добавить в каталог режим сортировки по подписи карточки по алфавиту (А–Я), регистронезависимый, с учётом русской локали.
- Добавить в шапку каталога две доступные кнопки управления: «По алфавиту (А–Я)» и «Сбросить».
- Сортировка применяется к текущему набору видимых карточек (и пользовательским, и стартовым), влияет только на порядок отображения, не меняет хранилище.
- «Сбросить» возвращает исходный порядок: пользовательские карточки по времени добавления (новые сверху), затем стартовые в фиксированном порядке.
- Нумерация «Мем NN» и eager‑loading первых трёх изображений следуют текущему порядку отображения.
- Режим сортировки не сохраняется в localStorage — после перезагрузки всегда используется исходный порядок.

## Capabilities

### New Capabilities
- catalog/sort-and-reset: Возможность сортировать текущий каталог карточек по алфавиту и сбрасывать его к исходному порядку без изменения данных.

### Modified Capabilities
- (none)

## Impact

- UI: добавление двух кнопок управления в секции каталога.
- Логика рендера: применение `Intl.Collator('ru', { sensitivity: 'base' })` для сортировки, стабильная сортировка при совпадении названий; отсутствие побочных эффектов для исходных массивов.
- Тесты: покрытие сценариев сортировки, сброса, стабильности при равных названиях и отсутствия персистенции режима.
