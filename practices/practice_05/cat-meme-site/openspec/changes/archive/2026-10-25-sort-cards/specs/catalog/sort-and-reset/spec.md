# Spec Delta

## Purpose
Возможность сортировать текущий каталог карточек по алфавиту и сбрасывать его к исходному порядку без изменения данных.

## ADDED Requirements

### Requirement: Alphabetical sort mode
Система SHALL предоставлять режим сортировки видимых карточек по подписи (title) по алфавиту А–Я, регистронезависимо, с локалью `ru`. Сортировка применяется к объединённому списку пользовательских и стартовых карточек и влияет только на порядок отображения.

#### Scenario: Sort enables A–Я order
- **WHEN** пользователь нажимает кнопку «По алфавиту (А–Я)»
- **THEN** карточки отображаются в порядке по возрастанию по `title` с учётом русской локали и без учёта регистра

#### Scenario: Stable order on equal titles
- **WHEN** два или более элемента имеют одинаковый `title`
- **THEN** их взаимный порядок SHALL оставаться стабильным относительно исходной последовательности

### Requirement: Reset to default order
Система SHALL предоставлять сброс к исходному порядку отображения: сначала пользовательские карточки в порядке добавления (новые сверху), затем стартовые в фиксированном порядке.

#### Scenario: Reset restores base order
- **WHEN** пользователь нажимает кнопку «Сбросить»
- **THEN** порядок карточек возвращается к базовому: `[userCards (новые сверху), starterCards (исходный порядок)]`

### Requirement: Display-only sorting
Сортировка SHALL не изменять исходные данные и хранилище. Базовые массивы пользовательских и стартовых карточек не модифицируются, сортировка применяется к временной копии для рендера.

#### Scenario: No persistence of sort mode
- **WHEN** пользователь перезагружает страницу после включения сортировки
- **THEN** порядок карточек отображается по умолчанию (без сохранения режима сортировки)

### Requirement: Index labels and eager loading follow current order
Отображаемая нумерация «Мем NN» и eager‑загрузка первых трёх изображений SHALL соответствовать текущему порядку карточек на экране.

#### Scenario: Labels and eager loading match view
- **WHEN** пользователь включает сортировку А–Я
- **THEN** «Мем NN» и eager‑загрузка применяются к первым трем карточкам новой последовательности
