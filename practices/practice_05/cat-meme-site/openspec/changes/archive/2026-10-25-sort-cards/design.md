# Design

## Context

Каталог рендерится из двух массивов: `userCards` (восстановленные и новые карточки) и фиксированный `starterCards`. Отображение строится через `cards = [...userCards, ...starterCards]` и ререндер полного грида. Валидация и ограничения уже заданы модулем `src/card-validation.mjs` и правилами проекта: не использовать `innerHTML`, сохранять доступность, принимать только абсолютные HTTP(S) URL.

## Goals / Non-Goals

**Goals:**
- Добавить доступные элементы управления сортировкой и сбросом в шапке каталога.
- Реализовать регистронезависимую сортировку по русской локали для всех видимых карточек.
- Сохранить неизменность исходных массивов; сортировка применяется только к временной копии.
- При сбросе восстановить исходный порядок: `[userCards (новые сверху), starterCards (фиксировано)]`.

**Non-Goals:**
- Персистенция режима сортировки.
- Дополнительные режимы сортировки (Я–А, по дате, по alt и т.п.).
- Изменение контракта валидации карточек или MCP.

## Decisions

1. Контроллер сортировки: две кнопки «По алфавиту (А–Я)» и «Сбросить» в секции каталога.
   - Альтернатива: переключатель (toggle) с `aria-pressed`. Отклонено для простоты и явности двух действий.

2. Компаратор сортировки: `Intl.Collator('ru', { sensitivity: 'base' })`.
   - Плюсы: корректная русская коллация, регистронезависимость, переносимость.
   - Альтернатива: `localeCompare('ru')`. Работает, но использование `Collator` даёт явный контроль и производительность при многократных сравнениях.

3. Стабильность: не мутировать исходные массивы; сортировать клонированный `view = [...userCards, ...starterCards]`.
   - Tie‑break: при равных `title` сохранять базовый порядок (стабильная сортировка). Реализуем через индексы исходной последовательности как вторичный ключ.

4. Нумерация и eager‑loading: вычисляются из текущего индекса отображаемой последовательности.
   - Альтернатива: «закрепить» подсчёт по базовому порядку. Отклонено ради согласованности интерфейса: порядок = индекс.

5. Доступность: создать кнопки через DOM API, задать понятные названию и роли, фокус‑контуры соответствуют стилю (`:focus-visible`).

## Risks / Trade-offs

- [Коллация смешанных алфавитов] → Дополнительно протестировать строки с латиницей и цифрами; ожидаемое поведение — порядок по правилам локали `ru`.
- [Производительность при больших списках] → Объём до 50 пользовательских + ~6 стартовых карточек — сортировка не критична; при росте упереться в ререндер всего грида. Смягчение: минимальные изменения, отсутствие персистенции режима.
- [Стабильность при равных заголовках] → Явный вторичный ключ по исходному индексу; сценарий покрывается тестом.
