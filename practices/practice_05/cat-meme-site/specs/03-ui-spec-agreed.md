# UI Spec — Избранные котики (согласованная версия)

Контекст: добавляем лайки на карточки и переключатель фильтра «Только избранные», придерживаясь правил проекта: безопасный DOM (без `innerHTML`), доступность, видимый фокус, короткие анимации с уважением `prefers-reduced-motion`.

## Элементы Интерфейса

1. Кнопка лайка на карточке
   - Тип: `button` (`type="button"`).
   - Доступность: состояние через `aria-pressed` (`true`/`false`). Доступное имя меняется по состоянию: «Добавить в избранные» / «Убрать из избранных».
   - Содержимое: символ сердца (SVG через безопасный DOM или CSS) + текст (может быть visually-hidden); текст задаётся через `textContent`.
   - Расположение: правый верх карточки, не перекрывает важные подписи/фокус.
   - Идентификация: `data-card-id` для связи с логикой.
   - Клавиатура: `Enter`/`Space` переключают состояние.

2. Переключатель «Только избранные» в панели каталога
   - Тип: тоггл-кнопка `button` с `aria-pressed`.
   - Метка: видимый текст «Только избранные» + компактный текст состояния («Включён»/«Выключен»).
   - Счётчик: рядом элемент со значением количества видимых карточек; изменения объявляются через `aria-live="polite"`.
   - Расположение: рядом с заголовком/сортировкой в секции каталога. На узких экранах переносится на новую строку.
   - Клавиатура: `Enter`/`Space` переключают фильтр.

## Состояния

Кнопка лайка
- Неактивен: `aria-pressed="false"`, контур сердца, доступное имя «Добавить в избранные».
- Активен: `aria-pressed="true"`, заполненное сердце (тёплый жёлтый по гайду), имя «Убрать из избранных».
- Hover: ненавязчивая подсветка.
- Focus-visible: отчётливое кольцо/рамка; контраст достаточен.

Переключатель «Только избранные»
- Выключен: `aria-pressed="false"`; счётчик показывает общее число видимых карточек без фильтра.
- Включен: `aria-pressed="true"`; сетка показывает только карточки с ID из `getFavoriteIds()`; счётчик показывает их количество.
- Hover/focus-visible: как выше, фокус заметен.

## Пустое состояние (Empty State)

Условия: фильтр «Только избранные» включён и список избранных пуст (`getFavoritesCount() === 0`).

Отображение в области сетки:
- `role="region"` + заголовок через `aria-labelledby`.
- Заголовок: «Ещё нет избранных котиков».
- Описание: «Поставьте сердечко на понравившейся карточке — и она появится здесь».
- Кнопка действия: «Снять фильтр» — переводит переключатель в `aria-pressed="false"` и возвращает полный каталог.
- Иллюстрация (опционально): нейтральный кот, валидный `alt`; при ошибке изображения — доступный fallback.

## Обработка ошибок

Источник ошибок: только результат `toggleFavorite(id)` из модуля логики, который возвращает `{ ok: boolean, isFavorite: boolean, error?: string }`.

Коды: `error: 'storage_quota_exceeded'` при переполнении/запрете хранилища.

UI-реакция:
- При клике по лайку вызывается `toggleFavorite(id)`.
  - Если `ok === true`: кнопка обновляет `aria-pressed` по `isFavorite`, сетка/счётчик обновятся через событие.
  - Если `ok === false`: визуально откатываем кнопку к предыдущему состоянию, показываем краткое inline сообщение рядом с кнопкой («Не удалось сохранить лайк. Попробуйте ещё раз.») в элементе c `role="alert"`. Фокус остаётся на кнопке.
- Ошибки фильтра отсутствуют: фильтрация выполняется в UI по массиву ID, полученному из `getFavoriteIds()`.
- Сообщения создаются безопасно: только DOM API и `textContent`. Никакого `innerHTML`.

## Интеграция с логикой (согласованный контракт)

Модуль логики управляет только списком ID избранных. UI сам фильтрует карточки каталога.

Синхронные методы (UI вызывает напрямую):
- `isFavorite(id: string): boolean` — для начальной отрисовки состояний лайков.
- `toggleFavorite(id: string): { ok: boolean, isFavorite: boolean, error?: string }` — переключение лайка.
- `getFavoriteIds(): string[]` — получение списка избранных для фильтрации.
- `getFavoritesCount(): number` — количество избранных для счётчика и empty state.

События:
- Изменения избранных: `window` слушает `favorites:changed`.
  - Формат: `new CustomEvent('favorites:changed', { detail: { ids: string[] } })`.
  - Реакция UI: обновить состояния кнопок лайка на видимых карточках; если фильтр включён — перефильтровать сетку; обновить счётчик и `aria-live`.

## Визуальные и доступностные правила

- Видимый фокус на кнопке лайка, переключателе фильтра и кнопке «Снять фильтр».
- Цвет статуса дублируется символом (сердце) и текстом состояния.
- Минимальные размеры текста: основной 16 px, подписи 14 px.
- Короткие анимации; уважаем `prefers-reduced-motion`.
- На ширине ≤ 760 px элементы панели каталога не создают горизонтального скролла.

## UX микрокопия

- Лайк (неактивен): «Добавить в избранные».
- Лайк (активен): «Убрать из избранных».
- Фильтр выключен: «Только избранные — Выключен».
- Фильтр включен: «Только избранные — Включён».
- Ошибка лайка: «Не удалось сохранить лайк. Попробуйте ещё раз.».
- Пустое состояние: «Ещё нет избранных котиков» + «Поставьте сердечко…», кнопка «Снять фильтр».
