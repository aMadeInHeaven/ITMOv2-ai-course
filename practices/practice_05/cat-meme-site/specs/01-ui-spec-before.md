# UI Spec — «Избранные котики (Лайки)»

Цель: добавить лайки на карточки котов и переключатель фильтра «Только избранные» в каталоге, сохраняя правила проекта: безопасный DOM (без `innerHTML`), доступность, видимый фокус, валидные абсолютные URL изображений и общие визуальные принципы.

## Элементы Интерфейса

1. Кнопка лайка на карточке кота
   - Тип: `button` с `type="button"`.
   - Роль/доступность: используется атрибут `aria-pressed` для отражения состояния «лайкнуто» (true/false). Доступное имя меняется по состоянию: «Добавить в избранные» / «Убрать из избранных».
   - Расположение: в пределах карточки, закрепление в правом верхнем углу карточки, поверх изображения, с достаточным контрастом.
   - Содержимое: иконка сердца и визуально скрытый текст (например, через класс visually-hidden). Иконка создаётся безопасно через DOM (`createElement`/`createElementNS` для SVG) или CSS background; пользовательский текст — только через `textContent`.
   - Клавиатура: `Enter` и `Space` переключают состояние лайка. Фокус видим и не перекрывается.
   - Идентификация: кнопка содержит `data-card-id` для связи с логикой.

2. Переключатель фильтра «Только избранные» в секции каталога
   - Тип: кнопка-тоггл `button` c `aria-pressed` (альтернатива — `input[type=checkbox]` с ассоциированной меткой; используем кнопку для единообразия с лайком).
   - Метка: видимый текст «Только избранные» плюс компактный текст состояния («Включён»/«Выключен») или символический индикатор, дублирующийся текстом.
   - Расположение: панель каталога рядом с заголовком и управляющими элементами сортировки.
   - Счётчик: рядом отображается количество видимых карточек каталога. Обновляется при смене состояния фильтра. Для ассистивных технологий изменения объявляются через `aria-live="polite"` на отдельном элементе счётчика.
   - Клавиатура: `Enter` и `Space` переключают фильтр. Фокус видим.

## Состояния Элементов

Лайк (кнопка на карточке)
- Неактивен: `aria-pressed="false"`. Иконка контура сердца. Контраст соответствует гайду. Текст доступного имени: «Добавить в избранные».
- Активен: `aria-pressed="true"`. Иконка заполненного сердца. Цвет тёплый жёлтый согласно стилю, допускается мягкая анимация (учитывая `prefers-reduced-motion`). Текст доступного имени: «Убрать из избранных».
- Hover: подсветка границы/фона согласно визуальному гайду, без смещения контента.
- Focus-visible: отчётливое кольцо/рамка фокуса с достаточным контрастом, не мешающее чтению заголовка карточки.

Фильтр «Только избранные» (тоггл-кнопка)
- Выключен: `aria-pressed="false"`. Текст состояния: «Выключен». Счётчик показывает общее число карточек.
- Включен: `aria-pressed="true"`. Текст состояния: «Включён». В сетке остаются только лайкнутые карточки; счётчик показывает их количество.
- Hover: контрольная подсветка.
- Focus-visible: заметное кольцо/рамка фокуса.

## Пустое Состояние (Empty State)

Когда фильтр «Только избранные» включён, но нет ни одной лайкнутой карточки:
- В сетке вместо карточек отображается пустое состояние.
- Маркировка области: `role="region"` с заголовком через `aria-labelledby`.
- Содержимое:
  - Заголовок: «Ещё нет избранных котиков».
  - Описание: «Поставьте сердечко на понравившейся карточке — и она появится здесь».
  - Кнопка действия: «Снять фильтр» (возвращает все карточки, переводит фильтр в состояние `aria-pressed="false"`).
  - Иллюстрация/значок: нейтральный плейсхолдер-кот, доступный `alt` и отсутствие навязывающих эмоций. Если используется изображение, соблюдаются правила абсолютного URL; при ошибке изображения — доступный fallback.

## Ошибки Интерфейса

Типы ошибок и их отображение:
- Ошибка лайка (например, отказ записи в `localStorage`): на карточке показывается краткое текстовое сообщение рядом с кнопкой лайка («Не удалось сохранить лайк. Попробуйте ещё раз.»). Сообщение входит в элемент с `role="alert"` для мгновенного озвучивания, исчезает после исправления или закрытия.
- Ошибка фильтра (например, логика не вернула список): панель каталога показывает ненавязчивое уведомление («Не удалось применить фильтр»), `aria-live="polite"`.
- Глобальная ошибка хранения (запрет или переполнение хранилища): верхний баннер статуса с текстом и символом, не перекрывающий контент. Кнопка «Подробнее» раскрывает инструкцию. Баннер имеет `role="alert"`.
- Все сообщения оформляются через безопасный DOM: текст добавляется через `textContent`, без `innerHTML`.

Поведение при ошибках:
- Кнопка лайка временно отключается (атрибут `disabled`) при повторной попытке записи; фокус не теряется, есть визуальное состояние disabled.
- При частичной недоступности хранилища фильтр продолжает работать на данных, доступных в памяти, с явным предупреждением.

## Запрос к Команде Логики

UI ожидает следующий модуль логики карточек и лайков. Имена и сигнатуры выбраны удобно для фронтенда; реализация может быть синхронной, но интерфейс допускает промисы для будущей асинхронности.

Объекты данных
- Card: `{ id: string, title: string, imageUrl: string, altText: string, liked: boolean }`.
- ErrorLike: `{ code: string, message: string, cause?: unknown }`.

Методы
- `getCards(): Promise<Card[]> | Card[]`
  Возвращает все карточки каталога, включая стартовые и пользовательские, с актуальным полем `liked`.

- `getLikedIds(): Promise<string[]> | string[]`
  Возвращает массив `id` лайкнутых карточек.

- `isLiked(cardId: string): Promise<boolean> | boolean`
  Возвращает состояние лайка для заданной карточки.

- `toggleLike(cardId: string): Promise<{ cardId: string, liked: boolean }> | { cardId: string, liked: boolean }`
  Переключает лайк для карточки. Обновляет хранилище и внутреннее состояние. В случае ошибки отклоняется/выбрасывает `ErrorLike` с кодами: `storage_unavailable`, `storage_quota`, `card_not_found`.

- `getVisibleCards(options: { onlyLiked: boolean }): Promise<Card[]> | Card[]`
  Возвращает список карточек для рендера сетки с учётом фильтра «Только избранные».

- `getCounts(): Promise<{ total: number, liked: number }> | { total: number, liked: number }`
  Возвращает общее число карточек и число лайкнутых для счётчика в панели каталога.

- `subscribe(handler: (event: { type: 'cardsChanged' | 'likesChanged' | 'storageError', payload?: unknown }) => void): () => void`
  Подписка UI на изменения. События:
  - `likesChanged`: когда меняется лайк любой карточки; payload может содержать `{ cardId, liked }` и новый массив `likedIds`.
  - `cardsChanged`: когда изменяется состав каталога (добавление/удаление).
  - `storageError`: при ошибке чтения/записи; payload — `ErrorLike`.

Хранилище и инварианты
- Все карточки хранятся под ключом `cat-meme-cards:v1` (см. общий модуль валидации). Поля `title`, `altText`, `imageUrl` проходят проверку `src/card-validation.mjs`; URL изображений — только абсолютные `http:`/`https:`.
- Модуль логики не использует `innerHTML`. Любые текстовые вставки — через `textContent` в UI.
- Ошибки изображений обрабатываются существующим доступным fallback; лайки не нарушают этот механизм.

## Визуальные и Доступностные Правила

- Видимый фокус на всех интерактивных элементах (кнопка лайка, кнопка фильтра, кнопка «Снять фильтр» в пустом состоянии).
- Цветовое кодирование дублируется текстом или символом. Для лайка символ сердца, для фильтра текст состояния.
- Минимальные размеры текста: соответствует гайду (основной 16 px, подписи 14 px).
- Анимации короткие, уважают `prefers-reduced-motion`.
- На ширине до 760 px панель каталога и сетка остаются без горизонтального скролла; переключатель фильтра переносится на новую строку при необходимости.

## UX Микрокопия

- Лайк (неактивен): «Добавить в избранные».
- Лайк (активен): «Убрать из избранных».
- Фильтр выключен: «Только избранные — Выключен».
- Фильтр включен: «Только избранные — Включён».
- Пустое состояние: Заголовок «Ещё нет избранных котиков», описание «Поставьте сердечко на понравившейся карточке — и она появится здесь», кнопка «Снять фильтр».
- Ошибка лайка: «Не удалось сохранить лайк. Попробуйте ещё раз.».
- Ошибка фильтра: «Не удалось применить фильтр».

## Тестируемые Сценарии (ориентиры)

- Кнопка лайка переключается клавишами `Enter`/`Space`, `aria-pressed` обновляется.
- Переключатель фильтра меняет видимую выборку, счётчик обновляется и озвучивается через `aria-live`.
- Пустое состояние выводится при включённом фильтре и отсутствии лайков, содержит кнопку «Снять фильтр».
- Ошибка записи и чтения хранилища вызывает соответствующие пользовательские уведомления, не нарушая фокус.
