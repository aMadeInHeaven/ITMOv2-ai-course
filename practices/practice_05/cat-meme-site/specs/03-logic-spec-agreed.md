# Logic Spec — Избранные котики (согласованная версия)

## 1. Модель данных и хранилище

- Ключ `localStorage`: строго `cat-meme-favorites:v1`.
- Формат хранения: JSON-массив идентификаторов карточек `string[]`.
  - Пример: `["card-123", "card-456"]`.
  - Порядок соответствует порядку добавления.
  - Дубликаты отсутствуют.
- Оперативное представление: внутренний `Set<string>` как кэш для O(1) проверки любимости и массив для сериализации.
- Лимит: максимум 50 ID. Попытки превысить лимит отклоняются.

## 2. Публичный API

Имена и сигнатуры согласованы с UI. Возвращаемые значения устойчивы и детерминированы.

- `isFavorite(id: string): boolean`
  - Проверяет, находится ли `id` в избранном.
  - Время выполнения: O(1) на основе внутреннего `Set`.
  - Валидация: некорректный `id` трактуется как отсутствующий и возвращает `false`.

- `toggleFavorite(id: string): { ok: boolean, isFavorite: boolean, error?: string }`
  - Переключает статус: если `id` был в избранном — удаляет, иначе — добавляет.
  - Успешный результат: `{ ok: true, isFavorite: boolean }`, где `isFavorite` отражает новый статус после операции.
  - Ошибка квоты `QuotaExceededError`: `{ ok: false, isFavorite: false, error: 'storage_quota_exceeded' }`.
  - Некорректный `id`: `{ ok: false, isFavorite: false, error: 'invalid_id' }`.
  - Превышение лимита: `{ ok: false, isFavorite: false, error: 'limit_exceeded' }`.

- `getFavoriteIds(): string[]`
  - Возвращает копию массива всех избранных ID из актуального состояния стора.
  - Гарантирует иммутабельность возвращаемого массива.

- `getFavoritesCount(): number`
  - Возвращает количество избранных ID из кэша `Set`.

## 3. События и синхронизация

- Унифицированное событие изменений: `favorites:changed` на `window`.
  - Диспетчеризация: `window.dispatchEvent(new CustomEvent('favorites:changed', { detail: { ids: string[] } }))`.
  - Событие эмитится после успешной операции изменения состава избранного (`toggleFavorite`), а также после восстановления/перезагрузки из хранилища.
  - UI подписывается на событие и синхронизирует представление.

- Межвкладочная синхронизация:
  - Слушать нативное событие `storage` браузера.
  - При изменении ключа `cat-meme-favorites:v1` модуль перечитывает и валидирует данные; по итогу испускает `favorites:changed` с актуальным `ids`.

## 4. Валидация и ограничения

- Валидация ID:
  - Тип: `string`.
  - Длина: 1–64 символа.
  - Формат: `^[A-Za-z0-9_-]{1,64}$`.
  - Для `isFavorite` некорректный `id` возвращает `false` без ошибок.
  - Для `toggleFavorite` некорректный `id` возвращает `{ ok: false, isFavorite: false, error: 'invalid_id' }`.

- Лимит количества:
  - Максимум 50 ID.
  - На попытку добавить сверх лимита `toggleFavorite` возвращает `{ ok: false, isFavorite: false, error: 'limit_exceeded' }`.

- Структура хранилища:
  - При чтении из `localStorage` ожидается корректный JSON-массив строк.
  - Повреждённый JSON или неверный тип приводит к восстановлению пустого списка и последующей записи в хранилище (при возможности). После восстановления эмитится `favorites:changed`.

## 5. Обработка ошибок и краевые случаи

- `QuotaExceededError` при `localStorage.setItem`:
  - Операция переключения не применяется; состояние памяти и хранилища остаётся прежним.
  - Возвращаемая форма строго: `{ ok: false, isFavorite: false, error: 'storage_quota_exceeded' }`.

- Дубликаты:
  - При добавлении уже существующего ID `toggleFavorite` переключает в сторону удаления (нормальная логика toggle).

- Отсутствующий элемент при удалении через toggle:
  - При переключении несуществующего ID — добавление, если не нарушает лимит.

- Повреждённый JSON:
  - При инициализации/перечтении: если `JSON.parse` падает или формат не `string[]`, применяется восстановление (пустой массив). После восстановления генерируется `favorites:changed`.

- Неизвестные ошибки записи:
  - Любые иные исключения при `setItem` трактуются как ошибка записи. Возврат `{ ok: false, isFavorite: false, error: 'storage_write_failed' }`. Состояние не меняется.

## 6. Нефункциональные требования

- Производительность:
  - `isFavorite` — O(1) за счёт `Set`.
  - `toggleFavorite` — O(1) для кэша; сериализация массива до 50 элементов — O(n), где `n ≤ 50`.
  - `getFavoriteIds` — O(n) с копированием.
  - `getFavoritesCount` — O(1).

- Надёжность и консистентность:
  - Запись в storage атомарна на уровне `setItem`; при ошибках операция откатывается.
  - Синхронизация между вкладками обеспечивается через `storage`-событие и единый `favorites:changed`.

- Безопасность:
  - Модуль работает только с идентификаторами; пользовательские строки не вставляются в `innerHTML`.
