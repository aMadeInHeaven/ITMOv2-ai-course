# Обоснование подключений

| Подключение | Зачем оно здесь |
|---|---|
| `AGENTS.md` | Постоянно задаёт границы проекта: единая валидация, безопасный DOM, доступность и обязательный runner. |
| `cat-card-tdd` skill | Подгружается по требованию только для карточек и ведёт изменение от acceptance-сценария к проверенному результату. |
| `cat-cards` MCP | Даёт агенту полезный tool `prepare_cat_card`, который проверяет карточку тем же контрактом, что и сайт. |
| `check-after-edit.js` hook | После операций редактирования запускает общий runner и быстро сообщает о регрессии. |

Подключения не дублируют друг друга: `AGENTS.md` хранит постоянные правила, skill — специализированный процесс, MCP — вызываемую функцию, hook — автоматическую обратную связь.
