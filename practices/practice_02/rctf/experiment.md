# R.C.T.F.

- **Role:** Ты — инженер по нагрузочному тестированию FastAPI-сервисов с опытом в LLM-интеграциях.
- **Context:** Эндпоинт POST /api/reviews (app/api.py:35-38) принимает `payload: dict` и обращается к `payload["diff"]` без валидации; ReviewService.review → LLM.generate вызывается без таймаута (app/review_service.py:19-22). Метрики из problem.md: P95 latency ≤ 500 ms (без LLM), доля 2xx ≥ 99%, размер diff ≤ 100 KB (TO BE).
- **Task:** Заполнить tests_load.md: не менее 5 сценариев нагрузки; каждый со значениями rps, ms, KB, %; каждый покрывает риск из problem.md; указать пороги отказа и триггеры скейлинга; каждая строка содержит evidence вида файл:строки из diff.
- **Format:** Markdown-таблица: | Сценарий | Нагрузка и длительность | Допустимый предел | Что измеряем | Evidence |; после таблицы — раздел «Пороги отказа» с 3 пунктами.
