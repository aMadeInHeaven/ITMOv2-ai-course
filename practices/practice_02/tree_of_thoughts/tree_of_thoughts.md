# Техника: Tree of Thoughts (ToT)

## Цель
Рассмотреть 3 альтернативных подхода к нагрузочному тестированию tests_load.md и выбрать лучший по критериям.

## Промт

**Задача:** улучшить tests_load.md.

**Альтернатива A: Минимальная**
- Оставить 2 сценария, добавить только числа.
- Плюсы: быстро, не перегружает.
- Минусы: не покрывает все риски.

**Альтернатива B: Полная матрица**
- 10+ сценариев: rps, timeout, DoS, типы, размеры, параллельность.
- Плюсы: максимальное покрытие.
- Минусы: избыточно для MVP, долго.

**Альтернатива C: Сбалансированная**
- 5 сценариев: покрывают все риски из problem.md, но без избыточности.
- Плюсы: покрытие + скорость.
- Минусы: компромисс.

**Критерии выбора:**
1. Покрытие рисков из problem.md
2. Воспроизводимость
3. Связь с метриками
4. Трудозатраты

**Выбор:** обосновать и реализовать выбранную альтернативу.

## Ожидаемый результат
tests_load.md с 5 сценариями + обоснование выбора альтернативы.

## Как проверить
- [ ] 3 альтернативы описаны
- [ ] Критерии выбора явные
- [ ] Выбор обоснован
- [ ] Финальный файл соответствует выбранной альтернативе
