# Нагрузочные сценарии для POST /api/reviews

## Метрики и ограничения
- P95 латентности ≤ 500 ms (react.md: 22-24)
- Доля 2xx ≥ 99% (react.md: 22-24)
- Размер ответа ≤ 100 KB (react.md: 22-24)

## Сценарии

1. Базовая латентность одиночного запроса
   - Описание: отправка одиночного корректного запроса на POST /api/reviews
   - Ожидаемо: P95 ≤ 500 ms, 2xx = 100%
   - Evidence: TRAINING_PR.diff: 35-38

2. Постоянная нагрузка 10 rps в течение 1 минуты
   - Описание: параллельная генерация 10 запросов/с на POST /api/reviews
   - Ожидаемо: P95 ≤ 500 ms, 2xx ≥ 99%
   - Evidence: TRAINING_PR.diff: 35-38

3. Граничные размеры тела запроса
   - Описание: проверить минимальный и максимально допустимый полезный объём; валидный payload на границе
   - Ожидаемо: 2xx ≥ 99%, P95 ≤ 500 ms, размер ответа ≤ 100 KB
   - Evidence: react.md: 22-24; TRAINING_PR.diff: 35-38

4. Защита от DoS через неожиданные типы
   - Описание: отправка payload с неожиданными типами/структурами для проверки устойчивости
   - Ожидаемо: ошибки корректно обрабатываются, 2xx не падает ниже 99% на валидных запросах; P95 ≤ 500 ms на валидных
   - Evidence: react.md: 22-24; TRAINING_PR.diff: 35-38

5. Смешанная нагрузка: /health + /api/reviews
   - Описание: параллельно 1 rps на GET /health и 10 rps на POST /api/reviews
   - Ожидаемо: /health стабилен (2xx=100%), /api/reviews соответствует метрикам выше
   - Evidence: TRAINING_PR.diff: 35-38, 40-42
