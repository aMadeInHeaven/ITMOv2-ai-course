# Техника: ReAct (Reasoning + Acting)

## Цель
Пошагово улучшить tests_load.md, чередуя рассуждение и действие, с явным лимитом шагов.

## Промт

**Разрешённые действия:**
- READ: прочитать файл
- THINK: проанализировать
- WRITE: изменить tests_load.md
- VERIFY: проверить evidence
- STOP: остановиться

**Лимит:** 6 шагов.

**Пример шагов:**

**Шаг 1. THINK:** какие риски из problem.md не покрыты в tests_load.md?
→ Не покрыты: DoS через типы, параллельная нагрузка.

**Шаг 2. READ:** посмотреть problem.md → метрики.
→ Метрики: P95 <= 500 ms, 2xx >= 99%, размер <= 100 KB.

**Шаг 3. WRITE:** добавить сценарий "Параллельные запросы 10 rps".
→ Строка добавлена.

**Шаг 4. WRITE:** добавить сценарий "DoS через неожиданные типы".
→ Строка добавлена.

**Шаг 5. VERIFY:** проверить evidence у каждой строки.
→ Все строки имеют file:line.

**Шаг 6. STOP:** tests_load.md обновлён, 5 сценариев, evidence на месте.

## Ожидаемый результат
tests_load.md с 5 сценариями + журнал ReAct (6 шагов).

## Как проверить
- [ ] Есть журнал шагов
- [ ] Лимит 6 шагов соблюдён
- [ ] Каждое действие явное
- [ ] Финальный файл обновлён
